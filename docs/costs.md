# 運営コスト

Logos / CM Makerの運営にかかる費用の正本。API単価、ライセンス、計算資源、保存・配信費、実測値と試算をここへ集約する。

**最終確認日: 2026-07-20**

料金はUSD・税抜の概算。為替、リージョン、無料枠、契約、モデル改定で変わるため、予算確定時は必ずリンク先の公式料金を再確認する。無料枠は開発には利用できるが、本番の原価計画には含めない。

## CM動画1本の変動費

### 1. Gemini TTS

現在の実装:

- モデル: `gemini-3.1-flash-tts-preview`
- 声: `Schedar`
- 1本を5シーンに分けて生成
- 実データの音声長: 約33.5〜42.9秒

[Gemini API公式料金](https://ai.google.dev/gemini-api/docs/pricing)のStandard paid tier:

- テキスト入力: **$1.00 / 100万token**
- 音声出力: **$20.00 / 100万token**
- 音声は **1秒=25 token**

音声出力だけの試算:

```text
33.5秒 × 25 token × $20 / 1,000,000 = $0.01675
42.9秒 × 25 token × $20 / 1,000,000 = $0.02145
```

入力テキスト分は通常$0.001未満。したがって現状のTTSは、**1本あたり概ね$0.017〜$0.023、予算上は$0.02〜$0.03**で見る。

| 生成本数 | TTS変動費の目安 |
|---:|---:|
| 100本 | $2〜$3 |
| 1,000本 | $20〜$30 |
| 10,000本 | $200〜$300 |

GeminiのFree tierでは対象tokenが無料になる場合があるが、レート制限とデータ利用条件が異なるため、本番原価はpaid tierで計算する。

### 2. ブラウザプレビュー

TTS完成後は`@remotion/player`が利用者のブラウザ上で映像を組み立てる。サーバー側のMP4エンコードは発生しないため、専用の動画レンダリング従量費はない。通常のアプリ配信・音声ファイル配信費は別途発生する。

### 3. MP4レンダリング

2026-07-20のローカル実測:

| 項目 | 実測 |
|---|---:|
| 動画 | 33.5秒、1920×1080、30fps、1,022フレーム |
| 書き出し時間 | 約31.97秒 |
| CPU時間 | user 93.43秒 / system 11.50秒 |
| 最大常駐メモリ | 約0.76GB |
| MP4サイズ | 8.2MB（既存成果物は概ね6〜8MB） |

現在は「MP4ファイルを作成してダウンロード」を押したときだけ書き出す。キャンペーン生成時の自動MP4作成は行わない。

クラウド化後の計算資源は未実測。[AWS Lambda公式料金](https://aws.amazon.com/lambda/pricing/)のx86 first tierは、例示単価で **$0.0000166667 / GB-second**、無料枠は月400,000 GB-secondと100万request。ローカル実測を2GB・32秒の単一実行へ単純換算すると約$0.0011、同じ条件が5並列で32秒続く保守的な単純換算では約$0.0053となる。

これはRemotion Lambdaの分割、オーケストレーション、S3、データ転送を含まない机上値である。初期予算は**計算資源$0.01〜$0.05/本**を仮置きし、Remotion Lambda導入時に100本以上を実測して更新する。

## Remotionライセンス

[Remotion公式料金](https://www.remotion.dev/)の2026-07-20確認値:

- 個人および3名以下の会社: Free License、商用利用・自動化可
- 4名以上の会社で動画生成機能を提供する場合: Remotion for Automators
- Automators: **$0.01 / render、最低$100 / 月**

対象条件では、少量運用時はAWSなどの変動費より**月$100の最低利用額**が支配的になる。ローンチ前にチーム人数・法人単位・利用形態をRemotionへ確認する。

## MP4の保存・配信

[Cloudflare R2公式料金](https://developers.cloudflare.com/r2/pricing/)のStandard storage:

- 保存: **$0.015 / GB-month**
- Class A: **$4.50 / 100万操作**
- Class B: **$0.36 / 100万操作**
- インターネットへのegress: **無料**
- 月間無料枠: 10GB-month、Class A 100万回、Class B 1,000万回

MP4を1本8.2MBとして単純計算:

| 保存本数 | 保存容量 | 無料枠超過後の月額目安 |
|---:|---:|---:|
| 1,000本 | 約8.2GB | $0 |
| 10,000本 | 約82GB | 約$1.08/月 |
| 100,000本 | 約820GB | 約$12.15/月 |

操作回数、Cloudflareの請求単位切り上げ、Workers等の別サービス費は含まない。動画再生回数が増えてもR2自体のegressは無料だが、同一オリジンAPIやWorkersを経由する場合は、そのサービスの料金を別途確認する。

## 現時点の判断

- **TTS + ブラウザプレビューの自動生成はコスト的に現実的**。paid tier前提でも概ね$0.02〜$0.03/本
- **MP4は明示操作時のみ作成**する。費用よりも30秒前後の待ち時間、CPU占有、サーバーレス基盤の制約が主な理由
- MP4の保存費は小さい。初期はR2無料枠に収まる可能性が高い
- 4名以上の会社ではRemotionの月額最低料金が主要な固定費候補
- 「利用者に無料提供」と「運営原価ゼロ」は分けて考え、クォータと重複生成防止を入れる

## コスト管理ルール

1. 新しい外部API・有料インフラ・ライセンスを追加するときは、この文書へ単価、課金単位、公式URL、確認日を追加する
2. 推計と実請求を分けて記載し、実測前の値には必ず「仮置き」「机上値」と明記する
3. 同じ成果物は再利用し、リロード・再試行・多重クリックで重複課金しないよう冪等にする
4. API呼び出しにはユーザー単位・日単位の上限を設け、失敗・再試行を含む利用量を記録する
5. 料金表はベータ開始前、その後は最低でも月1回またはモデル変更時に再確認する
