# デバイスモックアップ修正メモ

Campaign LPのHeroおよびWorkflow Labで共用している3Dデバイスモックアップの保留事項。
Organization登録の整合性修正を優先するため、以下は次工程で対応する。

## 確認済みの問題

1. **回転時にデバイスが表示領域から欠ける**
   - LP側の`model-viewer`が高さ360px、デスクトップ時のカメラ距離が6.4mで、構図に余白がない。
   - 回転操作は可能だが、回転後も収まる安全領域や角度制限が設定されていない。
2. **PC・スマホのスクリーン素材が上下反転する**
   - GLBのスクリーン面UVと、画像・CanvasテクスチャのV軸方向が逆。
3. **スマホがノートPCへめり込む**
   - duoモデル内のスマホ位置が低く、ノートPCの本体と交差している。

## 修正方針

- GLB生成時にPC・スマホ両方のスクリーンUVのV座標を反転する。
- スマホを右上かつ手前へ移動し、PCから浮かせる。
- モデルの外周に最低15%程度のセーフエリアを確保する。
- LPの3Dステージを4:3基準かつデスクトップ時440〜480px程度へ広げる。
- カメラを引き、`camera-target`と回転可能範囲を設定して、許可した角度では欠けないようにする。
- 同じGLBを使うLPとWorkflow Labの両方で、PC・スマホ・duoの3種類を確認する。

## 既存LPへの反映範囲

- GLBのUV・端末位置を直して同じ公開パスへ配置すれば、既存LPにも再読み込み時に反映される。
- 表示領域、カメラ、回転制限は生成済みLPのHTMLへ埋め込まれているため、既存LPは再生成が必要。

## 完了条件

- 実スクリーンショットと生成Canvasのどちらも正しい上下方向で表示される。
- 初期表示と許可された全回転角度で端末が欠けない。
- スマホとPCのメッシュが交差せず、意図した重なりとして見える。
- LPとWorkflow Labで同じ修正結果になる。
